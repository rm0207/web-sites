# 凪森 — シンプルな企業サイト

HTMLとCSSのみ。写真と文章の2分割を中心にした学習用サイトです。
`index.html`をブラウザで開くだけで表示できます。

- index.html：見出し・段落・リンク・画像・会社概要
- style.css：文字・余白・色・Flexbox・メディアクエリ
- room.jpg：イメージ写真（Unsplash）

学習目安：1か月目にHTMLとCSSの基本、2か月目にFlexbox、3か月目にスマートフォン表示の調整。
JavaScript、ビルド、インストールは不要です。写真は実際の施工例ではありません。
写真取得元：https://images.unsplash.com/photo-1600210492486-724fe5c67fb0
